# Entangled v1.0.0 - Release Notes

**Release Date:** May 25, 2026

## 🎉 What's New

We're excited to announce the first stable release of **Entangled** - a free, open-source messaging app for Android that puts your privacy first.

### ✨ Key Features

- **🔒 Privacy-First Messaging** - No ads, no tracking, no data mining. Your conversations belong to you.
- **⚡ Real-Time Chat** - Instant message delivery with typing indicators and read receipts.
- **🎙️ Voice Notes** - Send crystal-clear voice messages when typing isn't convenient.
- **😊 Emoji Reactions** - Express yourself with reactions on any message.
- **📸 Media Sharing** - Share photos and images in full quality without compression.
- **🎨 Beautiful Themes** - Personalize your experience with multiple color themes.
- **🔔 Smart Notifications** - Stay informed without being overwhelmed.
- **👥 Friend Requests** - Connect securely with a simple request system.

### 🛡️ Security & Privacy

- End-to-end message encryption
- No phone number required
- No data collection or tracking
- Open-source codebase (fully auditable)
- Secure friend request system

### 📱 System Requirements

- **Android Version:** 8.0 (API 26) or higher
- **Storage:** ~15MB app size
- **Internet:** Required for real-time messaging

## 📥 Installation

### Option 1: Direct APK Download
1. Download the `entangled-v1.0.0.apk` from this release
2. Enable "Install from Unknown Sources" in Android settings
3. Install and enjoy!

### Option 2: Build from Source
```bash
git clone https://github.com/AkiTheMemeGod/Entangled.git
cd Entangled
flutter pub get
flutter build apk --release
```
